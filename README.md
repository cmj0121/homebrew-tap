# homebrew-tap

Homebrew tap for [cmj0121](https://github.com/cmj0121)'s tools.

```sh
brew install cmj0121/tap/baton
```

| Cask                                            | What it is                                        |
| ----------------------------------------------- | ------------------------------------------------- |
| [baton](https://github.com/cmj0121/baton)       | An extensible, agent-friendly terminal multiplexer |

The casks here are generated — each `baton` release pushes its own cask from
[`.goreleaser.yaml`](https://github.com/cmj0121/baton/blob/main/.goreleaser.yaml).
Edit that file, not this repository.
