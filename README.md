# homebrew-tap

Homebrew tap for [cmj0121](https://github.com/cmj0121)'s tools.

```sh
brew install cmj0121/tap/baton
brew install cmj0121/tap/loci
```

| Cask                                      | What it is                                         |
| ----------------------------------------- | -------------------------------------------------- |
| [baton](https://github.com/cmj0121/baton) | An extensible, agent-friendly terminal multiplexer |
| [loci](https://github.com/cmj0121/loci)   | Hands an agent's session over at git boundaries    |

The casks here are generated — each release pushes its own cask from the
tool's `.goreleaser.yaml` ([baton](https://github.com/cmj0121/baton/blob/main/.goreleaser.yaml),
[loci](https://github.com/cmj0121/loci/blob/main/.goreleaser.yaml)).
Edit that file, not this repository.
